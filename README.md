# Landing Page — The Odin Project

A simple landing page built with semantic HTML and CSS Flexbox.

## Run it
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in your browser.
3. Optional: use the Live Server extension in VS Code for automatic refresh.

## Customize
- Edit the text in `index.html`.
- Change colors, spacing, and layout in `style.css`.
- Replace the `.hero-image` placeholder with an actual image if you wish.

The page uses the Roboto font from Google Fonts; if you are offline, it falls back to Arial.
